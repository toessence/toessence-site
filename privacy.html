Політика конфіденційності

Оновлено: Травень 2026

Сервіс toEssence розроблено з урахуванням принципу максимального захисту приватності (Privacy by Design). Ми мінімізуємо збір даних, забезпечуємо сувору безпеку та ніколи не продаємо, не здаємо в оренду й не передаємо ваші дані третім сторонам з маркетинговою чи рекламною метою.

1. Вступ та відповідність вимогам Chrome Web Store

Для основної функції (генерація стислих описів статей, відео YouTube та відгуків) toEssence потребує доступу до певного вмісту вебсторінок. Ці дані обробляються виключно для надання послуги на ваш явний запит і відповідно до Google Chrome Web Store User Data Policy, включно з вимогами Limited Use.

2. Які дані ми збираємо та обробляємо

Ми збираємо лише дані, строго необхідні для роботи розширення. На безкоштовному тарифі (Free):

  • Анонімний UUID — генерується локально у браузері для ідентифікації сесії та контролю лімітів, без ідентифікації вас особисто.
  • Країна та регіон — визначається автоматично за IP-адресою (яка не зберігається) для відображення локальних цін.
  • Тип фільтра — знеособлені дані про тип контенту (новини, YouTube, відгуки).
  • Часова мітка — дата і час запиту.
  • URL сторінки та фрагмент тексту — коли ви явно запитуєте опис (наводячи курсор на заголовок), URL та фрагмент тексту статті або субтитрів надсилаються на наш сервер. URL та згенерований опис тимчасово кешуються для швидкодії; вихідний фрагмент тексту обробляється миттєво і не зберігається після створення опису.

Ми категорично НЕ збираємо: ім'я, номери телефонів або точну IP-адресу (використовується лише безповоротний хеш); всю історію переглядів чи профілі відвіданих сторінок. Дані обробляються лише в момент, коли ви активно запитуєте опис.

3. Як ми використовуємо дані

  • Робота сервісу, зокрема контроль і підрахунок ліміту безкоштовних запитів (10 фільтрів на день).
  • Формування анонімної статистики (кількість активних користувачів, популярність функцій) для покращення розширення.
  • Адаптація вартості Pro-підписки відповідно до країни користувача.

Важливо: ми не використовуємо ваші особисті дані чи дані переглядів для персоналізації реклами, створення маркетингових профілів або відстеження вас у мережі.

4. Pro-підписка та платежі

Обробку платежів безпечно забезпечує Lemon Squeezy (Merchant of Record).

  • Під час оплати Lemon Squeezy збирає email та платіжні реквізити.
  • toEssence зберігає лише анонімний UUID та статус підписки.
  • Ми не маємо доступу до банківської картки чи фінансових даних, які обробляє Lemon Squeezy.

5. Передача даних третім сторонам

Ми передаємо дані лише надійним сервіс-провайдерам, необхідним для роботи розширення. Ми ніколи не продаємо ваші дані.

  • OpenAI API — обробляє фрагменти тексту для генерації описів. Дані конфіденційні, зашифровані, не зберігаються для перегляду людьми та не використовуються для навчання моделей AI.
  • Supadata — використовується для отримання публічних субтитрів відео YouTube, для яких ви запитуєте опис.
  • Supabase — захищена хмарна база даних (регіон ЄС), що зберігає ваш UUID, статус підписки, анонімну статистику та тимчасовий кеш описів.
  • Lemon Squeezy — процесинг платежів як Merchant of Record (відповідає PCI-DSS).

6. Файли cookie та локальне сховище

Ми не використовуємо маркетингові чи трекінгові файли cookie. Анонімний UUID та налаштування інтерфейсу зберігаються локально на вашому пристрої через сховище браузера (Chrome Storage).

7. Терміни зберігання та безпека

  • Логи: детальні логи використання фільтрів автоматично й остаточно видаляються через 90 днів.
  • Статистика: агрегована повністю знеособлена статистика зберігається безстроково для моніторингу розвитку продукту.
  • Безпека: усі дані шифруються під час передачі (HTTPS/TLS) та зберігання (AES-256).

8. Права користувачів (GDPR та CCPA)

Ви зберігаєте повний контроль над своїми даними. Оскільки для користувачів Free ми не збираємо особистих ідентифікаторів на кшталт email, ваші дані пов'язані виключно з анонімним UUID. Для повного видалення даних напишіть на hello@toessence.net, вказавши анонімний UUID (його можна знайти в налаштуваннях розширення).
