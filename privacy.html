Політика конфіденційності

Оновлено: Травень 2026

Сервіс toEssence розроблено з урахуванням принципу максимального захисту приватності користувачів (Privacy by Design). Збір даних мінімізовано, і інформація ніколи не продається третім особам.

1. Які дані ми збираємо

На безкоштовному тарифі (Free):

  • Анонімний UUID — генерується локально у браузері користувача для ідентифікації сесії.
  • Країна та регіон — визначається автоматично за IP-адресою для коректного відображення локальних цін.
  • Тип фільтра — знеособлені дані про тип контенту (новини, YouTube, відгуки).
  • Часова мітка — дата і час здійснення запиту.

Ми категорично НЕ збираємо: ім'я, номери телефонів або точну IP-адресу (замість неї використовується безповоротний хеш), URL-адреси вебсторінок, повний вміст текстових статей або відео.

2. Як ми використовуємо дані

Інформація використовується виключно для забезпечення роботи сервісу:

  • Контроль і підрахунок ліміту безкоштовних запитів (1000 фільтрів на календарний місяць).
  • Формування анонімної статистики використання (кількість активних користувачів, популярність функцій).
  • Адаптація вартості Pro-версії відповідно до економічного регіону країни користувача.

3. Дані Pro-підписки та платежі

  • Обробку платежів забезпечує сертифікований сервіс Stripe.
  • Під час оплати Stripe збирає email та платіжні реквізити користувача.
  • toEssence зберігає лише унікальний UUID користувача та статус підписки.
  • Ми не маємо доступу до банківської картки чи електронної пошти користувача у Stripe.

4. Передача даних третім сторонам

  • Google Gemini API — обробляє текст контенту для генерації тез. Дані, передані через API, є конфіденційними, не зберігаються для перегляду людьми та не використовуються для навчання моделей AI.
  • Supabase — захищена хмарна база даних у регіоні ЄС (EU-Central) для зберігання анонімної статистики.
  • Stripe — міжнародний процесинг платежів із найвищим рівнем безпеки PCI-DSS.

5. Файли cookie та локальне сховище

Ми не використовуємо маркетингові або трекінгові файли cookie. Для зберігання UUID та налаштувань інтерфейсу використовується локальне сховище браузера (Chrome Storage).

6. Терміни зберігання та безпека

  • Детальні логи використання фільтрів автоматично видаляються через 90 днів.
  • Агрегована знеособлена статистика зберігається безстроково.
  • Застосовується шифрування даних під час передачі (HTTPS) та зберігання (AES-256).

7. Права користувачів (включаючи GDPR)

Користувач має повне право керувати своїми даними. Для видалення всієї інформації з бази даних надішліть запит на hello@toessence.net, вказавши анонімний UUID (його можна скопіювати в налаштуваннях розширення).

8. Зміни до політики конфіденційності

Ми залишаємо за собою право оновлювати цей документ. У разі внесення істотних змін користувачі будуть повідомлені через інтерфейс розширення або на офіційному сайті.
